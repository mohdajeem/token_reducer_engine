# Graph Schema - Semantic Context Engine

This document provides the complete structural schema definition of the queryable **Semantic Graph** generated by the GraphBuilder.

---

## 1. Graph Dictionary Schema Definition

The graph compiled by `GraphBuilder` is a plain Python/JSON dictionary containing file-scoped maps and global traversal arrays:

```python
graph = {
    "imports": {},             # file_path -> list of import dicts
    "routes": {},              # file_path -> list of normalized route dicts
    "calls": {},               # file_path -> list of function call dicts
    "database": {},            # file_path -> list of database operations
    "functions": {},           # file_path -> list of registered functions
    "errors": {},              # file_path -> list of throws/catches
    "contracts": {},           # file_path -> list of schema validation rules
    "parameters": {},          # file_path -> list of function parameter arrays
    "arguments": {},           # file_path -> list of call arguments indexed by call_id
    
    # Global Traced Vectors (Traced across files)
    "execution_edges": [],     # Graph nodes connectivity paths (ROUTE_CALL, FUNCTION_CALL, etc.)
    "data_flow": [],           # Mappings of arguments -> target parameters
    "taint_sources": [],       # Paths of user inputs and return taints
    "security_sinks": [],      # Monitored database query sinks
    "security_findings": [],   # Confirmed vulnerabilities
    "sanitizers": [],          # Applied sanitizer call wrappers
    "variable_states": [],     # Scoped and global variable assignments
    "returns": [],             # Registered function return values
}
```

## 2. Graph Node Definitions

### A. Route Node
*   **Structure**:
    ```json
    {
      "method": "POST",
      "path": "/login",
      "router": "router",
      "middlewares": [
        {
          "function": "authMiddleware",
          "resolved_file": "C:/app/middleware/auth.js",
          "resolved_function": {"name": "authMiddleware", "file": "C:/app/middleware/auth.js"}
        }
      ],
      "handler": {
        "controller": "authController",
        "function": "login",
        "resolved_file": "C:/app/controllers/authController.js",
        "resolved_function": {"name": "login", "file": "C:/app/controllers/authController.js"}
      }
    }
    ```

### B. Function Node
*   **Structure**:
    ```json
    {
      "name": "fetchUsers",
      "file": "C:/app/services/userService.js",
      "start_line": 26,
      "end_line": 32
    }
    ```

### C. Database Node
*   **Structure**:
    ```json
    {
      "model": "User",
      "operation": "find",
      "query": null,
      "connection": null,
      "function": "fetchUsers"
    }
    ```

## 3. Graph Edge Definitions (`execution_edges`)

Edges define directional context flows inside the static analysis runtime. Every edge contains a `from` node, a `to` node, and a `type`:

### A. `ROUTE_CALL`
*   **Flow**: Connects an HTTP endpoint (Route) directly to its target controller (Function).
*   **Example**:
    ```json
    {
      "from": {"type": "ROUTE", "route": "/login", "method": "POST"},
      "to": {"type": "FUNCTION", "file": "authController.js", "function": "login"},
      "type": "ROUTE_CALL"
    }
    ```

### B. `ROUTE_MIDDLEWARE`
*   **Flow**: Connects an HTTP endpoint (Route) to its execution middleware (Function).
*   **Example**:
    ```json
    {
      "from": {"type": "ROUTE", "route": "/login", "method": "POST"},
      "to": {"type": "MIDDLEWARE", "file": "auth.js", "function": "authMiddleware"},
      "type": "ROUTE_MIDDLEWARE"
    }
    ```

### C. `FUNCTION_CALL`
*   **Flow**: Connects a calling local function to its callee target function.
*   **Example**:
    ```json
    {
      "from": {"type": "FUNCTION", "file": "userController.js", "function": "getAllUsers"},
      "to": {"type": "FUNCTION", "file": "userService.js", "function": "fetchUsers"},
      "type": "FUNCTION_CALL"
    }
    ```

### D. `DB_ACCESS`
*   **Flow**: Connects a controller/service function to a database/SQL node.
*   **Example**:
    ```json
    {
      "from": {"type": "FUNCTION", "file": "userService.js", "function": "fetchUsers"},
      "to": {"type": "DATABASE", "model": "User", "operation": "find"},
      "type": "DB_ACCESS"
    }
    ```
