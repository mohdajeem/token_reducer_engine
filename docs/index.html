What it is

A graph, not an index

Tree-sitter parses every file. Calls, imports, class hierarchies, dispatch tables, injected fields and class attributes all become edges — and every edge carries a confidence label, from observed down to convention, so a caller can ask for only what it trusts.

Tools, not a library

Eleven MCP tools — build the graph, slice context for a symbol, compute a blast radius, list the tests that cover it, summarise a file. Any MCP-capable agent can call them; verified end-to-end against the OpenHands agent SDK.

Four languages, one engine

Python, JavaScript, TypeScript and Java share the same rules and traversal; only the query files differ. Framework conventions — Spring routes, pytest fixtures, JUnit annotations — are first-class edges, not guesses.

Measured, not claimed

Agentless (UIUC) is the strongest open baseline for this problem and publishes every intermediate result. We scored both on the same 30 SWE-bench Verified tasks, against the real fixes. Their numbers come from their released artifacts; ours were computed offline.

Read honestly: a three-prompt LLM pipeline still localises better than our static graph, because it understands the issue text. Where the graph wins is everything downstream — it picks a regression suite a fifth the size, with none of the tests the fix is meant to change, and it costs nothing to run. The two are complementary, and combining their file lists was perfect on this sample.

The one thing a laptop cannot do

Every number above was computed without a model. The last one needs compute.

Graph quality, localisation accuracy and test selection can all be scored offline against known-good fixes — which is how this project has been built with no cloud spend. What cannot be measured that way is the question that matters commercially: does an agent with this engine finish more work than the same agent without it? That is a paid, single-shot A/B run.

First

The A/B run

100 held-out SWE-bench Verified tasks, a stock agent, run twice — engine attached and detached. One variable, single shot, officially graded.

Then

Two more languages

Go and Rust, through the same loop that took Java from 14% to 94%: find a real repository, reproduce each breakage as a fixture, fix, keep it green.

Also

Publish the harness

The comparison scripts, the artifacts and the results — so the numbers on this page can be reproduced by anyone, including the ones where we lose.
